# GrowWise: My Learning Garden

**ปลูกเป็น: สวนทดลองของเรา** เป็นเกม 2D Isometric Pixel Art สร้างด้วย Godot 4.6.3 เริ่มจากสวนทดลองขนาดเล็ก แล้วพัฒนาเป็นบ้านสวน ฟาร์ม ชุมชน และเมืองเกษตรต้นแบบ ภาษาไทยเป็นค่าเริ่มต้นและสลับ English ได้ในเกม

โปรเจกต์อยู่ในโฟลเดอร์ `GrowWise/` แยกจาก WorldForge เดิม

## วงจรหลักของเกม

```text
สำรวจพื้นที่ → เก็บตัวอย่างดิน → ส่งแล็บ → เลือกพืชที่เหมาะ
→ ปลูก/ดูแล/เก็บเกี่ยว → เลี้ยงสัตว์/ตกปลา → ทำอาหารและแปรรูป
→ จัดสินค้าใส่รถ → ขนเข้าเมือง → นำกำไรกลับมาขยายบ้านและชุมชน
```

## ระบบฟาร์มและการเรียนรู้

- พืช 5 ชนิด: ผักบุ้ง คะน้า พริก มะเขือเทศ และแตงกวา
- พรวนดิน ปลูก รดน้ำ ใส่ปุ๋ย ถอนวัชพืช ตรวจพืช เก็บเกี่ยว และถอนต้นตาย
- พืชมี Growth Stage, ETA ถึงระยะถัดไปและ ETA ถึงเก็บเกี่ยว
- อาการขาดน้ำ น้ำมาก ดินเสื่อม แมลง โรค วัชพืช และต้นตาย
- วินิจฉัยปัญหา pH/NPK ระบบนิเวศ ปุ๋ยหมัก และชีวภัณฑ์
- ห้องทดลอง A/B/C เปรียบเทียบวิธีให้น้ำ
- ภารกิจการเรียนรู้ สมุดความรู้ และสรุปปลายฤดู
- คลังแสดงจำนวนคงเหลือทุกชิ้น และระบบคราฟต์แบบ `มี / ต้องใช้ / ขาด`

## ความก้าวหน้าและโลกที่มีชีวิต

- ระดับสวน 1–20 พร้อมชื่อระดับ รางวัล และระบบปลดล็อก
- Achievement, สมุดสะสม และประวัติฤดูกาล
- NPC รายวัน ความสัมพันธ์ คำขอชุมชน และเทศกาล
- กลางวัน–กลางคืน ร้านเปิด–ปิดตามเวลา และ NPC เปลี่ยนตำแหน่ง
- Feedback ลอยจากแปลง เช่น `+น้ำ`, `+XP`, `-เมล็ด`, ผลผลิตและคุณภาพ
- รายงานปลายฤดูแสดงผลผลิต น้ำ รายได้ ต้นทุน กำไร ดิน ความหลากหลาย อันดับ และคำแนะนำ

## ออโต้แบบตั้งกฎ

- ปิด / ช่วยดูแล / ฟาร์มอัตโนมัติ / โหมดเรียนรู้
- ตั้งเกณฑ์ความชื้นก่อนรดน้ำ
- เปิด–ปิดเก็บเกี่ยว ถอนวัชพืช ชีวภัณฑ์ ปุ๋ย ปลูก ขาย และคราฟต์
- ตั้งจำนวนเมล็ดขั้นต่ำและจำนวนผลผลิตก่อนขาย
- แสดงคิวงานถัดไปและประวัติสิ่งที่ออโต้ทำ

## บ้าน พื้นที่ ชุมชน และเมือง

- ซื้อพื้นที่ 5 โซน: สวนเดิม บ้านและงานช่าง ริมแม่น้ำ ชุมชน และเนินป่า/เหมือง
- สร้างและอัปเกรดบ้าน โรงเก็บของ ครัว โรงงานแปรรูป ท่าเรือ ตลาดปลา บ้านชาวเมือง ร้านค้า โรงเรียน คลินิก ศูนย์วิจัย ศาลากลาง เหมือง และค่ายป่า
- ประชากร ความสุข ชื่อเสียง รายได้เมือง ค่าใช้จ่ายรายวัน และระดับเมือง
- ฉากเมืองเติบโตตามจำนวนอาคารและประชากร

## การจัดการน้ำ

- ขุดร่องระบายน้ำและร่องส่งน้ำเป็นรายช่อง
- หมุนทิศทางน้ำ เหนือ/ใต้/ตะวันออก/ตะวันตก
- คันดินลดน้ำไหลเข้าจากฝนหนัก
- บ่อรับน้ำกักน้ำส่วนเกินไว้ใช้วันแห้ง
- ประตูน้ำควบคุมเครือข่าย และปั๊มน้ำเพิ่มแรงส่งโดยมีค่าเดินเครื่อง
- Inspector แจ้งว่าเมื่อน้ำมากควรขุดร่องไปทางใดหรือควรสร้างบ่อรับน้ำ
- ออโต้สามารถเปิดประตูน้ำและปั๊มตามสภาพแปลง

## รถขนส่งและตลาดเมือง

- รถเข็น รถกระบะ รถบรรทุกฟาร์ม และรถบรรทุกไฟฟ้า
- รถแต่ละชนิดมีความจุ เวลาเดินทาง ค่าขนส่ง และราคาขายในเมืองต่างกัน
- ระบบเลือกสินค้ามูลค่าสูงเข้ารถโดยอัตโนมัติ
- รถเดินทางบนฉากจริง มีเวลาคงเหลือ ประวัติเที่ยว และกำไรสุทธิ

## สำรวจพื้นที่และแล็บดิน

- สำรวจขอบแปลง ริมแม่น้ำ ที่ราบชุมชน ลาดเนินป่า และพื้นที่ลุ่มเค็ม
- เก็บตัวอย่างที่มี pH, N, P, K, อินทรียวัตถุ การระบายน้ำ ความเค็ม และความชื้น
- ส่งตรวจพื้นฐาน ตรวจน้ำ/การระบายน้ำ หรือรายงานฉบับสมบูรณ์
- งานแล็บใช้เวลา 1–2 วันในเกม
- รายงานจัดอันดับความเหมาะสมของพืช พร้อมสาเหตุและข้อเสนอแนะปรับปรุงดิน
- ปลูกพืชตามคำแนะนำอันดับหนึ่งได้รับโบนัสสุขภาพและคุณภาพ

## ตกปลา สำรวจ และกิจกรรมนอกฟาร์ม

- มินิเกมตกปลาแบบจับจังหวะ
- ปลา 7 ชนิด มีฤดูกาล อากาศ ความหายาก และคุณภาพ
- สำรวจป่าชุมชนเพื่อหาไม้และสมุนไพร
- สำรวจเหมืองเพื่อหาหินและเศษโลหะ โดยมีผลต่อคะแนนสิ่งแวดล้อม
- ทำอาหารจากผัก ปลา และสมุนไพรเพื่อเพิ่มมูลค่าและความสุขเมือง

## เลี้ยงสัตว์และการแปรรูป

- ไก่ เป็ด แพะ วัว และผึ้ง
- สร้างเล้า โรงเรือน รังผึ้ง และโรงผสมอาหารสัตว์
- สัตว์กินอาหารจากคลังจริง มีสุขภาพ ความสุข และรอบการให้ผลผลิต
- ผลผลิต: ไข่ไก่ ไข่เป็ด นมแพะ นมวัว น้ำผึ้ง และปุ๋ยคอก
- ผลิตอาหารเมล็ด อาหารหยาบ อาหารผสม และอาหารเสริมผึ้ง
- แปรรูปเป็นไข่ต้ม ไข่เค็ม นมพาสเจอร์ไรส์ ชีส น้ำผึ้งบรรจุขวด ปุ๋ยคอก ปลาแห้ง ซอสผัก และชุดอาหารฟาร์ม

## แต่งตัวละคร

- ชุดทำสวน ชุดกันฝน ชุดนักตกปลา ชุดช่าง ชุดนักวิจัย ชุดพนักงานขนส่ง และชุดผู้ดูแลเมือง
- ชุดแต่ละแบบมีสี รูปทรงหมวก และโบนัสกิจกรรมต่างกัน
- การแต่งตัวแสดงบนตัวละครในฉาก

## เปิดใน Godot

1. ติดตั้ง Godot 4.6.3
2. เปิด `GrowWise/project.godot`
3. กด Run Project

ข้อมูลระบบอยู่ในไฟล์ JSON ภายใต้ `GrowWise/data/` และข้อความหลักอยู่ใน `localization/th.json` กับ `localization/en.json`

## Windows Portable Build

Workflow `Build GrowWise Windows` จะ Import, ตรวจ GDScript, รัน Runtime smoke test, ติดตั้ง Export Templates และสร้าง `GrowWise.exe` พร้อม README และ SHA-256 checksum

Save อยู่ที่ `user://saves` รองรับ Windows user path ภาษาไทยและไม่ต้องใช้สิทธิ์ Administrator

## ขอบเขตของรุ่นนี้

เป็นเกม Farm-to-Town แบบ Single-player Portable Build ไม่มี online multiplayer, cloud save, voice acting หรือ content editor ภายนอกเกม ระบบขนาดใหญ่ทั้งหมดถูกทำเป็น Vertical Slice ที่เชื่อมกับคลัง เวลา เศรษฐกิจ และ Save จริง แต่ยังต้องทำ Manual Playtest ระยะยาวเพื่อปรับสมดุลราคา เวลา และ UI ก่อนถือเป็นรุ่นเชิงพาณิชย์
